# 个人文献管理系统 litmgr

本地、离线的个人文献管理桌面工具，面向论文收集、卡片整理、对照阅读和研究笔记。使用 **Python 3.12 + PySide6 6.8.3 + SQLite**，按模块分层，便于继续开发。

本仓库同时交接应用源码、四篇现有论文的数据快照，以及“论文翻译与卡片打包”技能源码和安装包。

## 当前功能

- 整体导入 TXT 卡片、正文 PDF、补充材料 PDF、翻译 Markdown 和附件；自动配对、查重及未知字段处理。
- 卡片字段统一管理，支持新增、编辑、归档和删除；字段分组支持新建、重命名、删除、筛选及移动字段。
- 搜索卡片、翻译正文及笔记；支持多词 AND、高级字段条件、阅读状态和星级过滤、保存检索。
- 标签、论文分组、阅读状态和星级；多选后的批量操作。
- PDF 和翻译并排阅读，支持公式、表格、页内查找、缩放；最近阅读记录可恢复阅读位置。
- 多条阅读笔记、字段修改历史及撤销；多篇论文按字段对比，差异高亮，可编辑并导出。
- 导出卡片 TXT、CSV 和 Markdown 对比表；数据库备份与恢复、多窗口、同库单实例保护。

## 仓库里的四篇论文和数据

`shared_library/` 是一次独立、完整的文献库快照，**用软件打开，不需要重新导入 PDF**。

| 内容 | 当前快照 |
| --- | ---: |
| 论文 | 4 篇 |
| PDF（正文及补充材料） | 7 份 |
| 翻译 Markdown | 4 份 |
| 已存卡片 TXT | 2 份 |
| 现行卡片字段 / 字段分组 | 27 / 6 |
| 已有数据库备份 | 6 份 |

字段值、阅读状态、星级、阅读历史、修改历史、标签/分组等均保存在 SQLite 中；即使没有独立卡片 TXT，论文也可有数据库里的字段值。当前笔记、标签、论文分组和保存检索的记录数为 0，未另行制造演示记录。

快照由 SQLite 在线备份生成，包含已经提交的数据；论文文件经过哈希检查。详情见 [快照清单](shared_library/snapshot_manifest.json)。运行锁、WAL/SHM 临时文件和日志不属于分享内容；`config.snapshot.json` 保留启动偏好和窗口布局并清空本机路径，供参考，不会自动覆盖你的个人设置。

建议先复制一份快照到仓库外使用，保持 Git 中这份交接基线便于比对。日常个人文献库由软件自身备份，不自动同步到 GitHub。

## 快速开始（Windows PowerShell）

准备 Python 3.12（64 位）和 Git。克隆私有仓库前，账号须已获访问权限；也可在 GitHub 点击 **Code → Download ZIP** 后解压。

```powershell
git clone https://github.com/GIGI-666/litmgr.git
cd litmgr
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\check_env.py
```

项目固定使用 PySide6 **6.8.3**。先按 `requirements.txt` 安装；安装依赖需要联网，软件本身及内置公式渲染可离线使用。

### 打开随仓库交接的四篇论文

以下复制命令只执行一次；目标已存在时换一个新的目录名，避免把两份文献库合并。

```powershell
Copy-Item -LiteralPath .\shared_library -Destination ..\litmgr-library -Recurse
.\.venv\Scripts\python.exe -m litmgr --library ..\litmgr-library
```

也可以直接查看仓库快照：

```powershell
.\.venv\Scripts\python.exe -m litmgr --library .\shared_library
```

直接打开会更新快照中的阅读历史等数据，Git 可能显示数据库已修改；日常试用推荐用前面的副本。

### 使用自己的空文献库

```powershell
.\.venv\Scripts\python.exe -m litmgr --library ..\my-literature-library
```

也可双击 `start.bat`，首次选择一个文献库文件夹，之后记住上次位置。命令行 `--library` 优先于上次记录。

## 日常使用

1. **导入论文**：点击“导入论文…”，选择单篇论文的文件夹或相关文件。核对卡片、PDF、翻译的配对和查重结果；未知字段可映射到已有字段或新建后再导入。
2. **编辑卡片**：双击列表中的论文打开详情，编辑“字段”页；失去焦点时自动保存。“文件”页可补加文件，“笔记”页可写多条笔记。
3. **调整字段和分组**：“字段管理…”中新增或编辑字段；“管理分组…”中改组名。删除分组只把字段移到“未分组”，保留字段和内容。永久删除字段则需要先归档，并会删除所有论文中该字段的值。
4. **阅读**：选中论文点击“阅读”，用顶部下拉框选择正文或补充材料 PDF，另一栏显示翻译；通过“最近阅读”可恢复已保存的阅读位置。
5. **查找与整理**：搜索框以空格分隔多个词，要求全部命中；范围可选卡片/指定字段/包含翻译和笔记。PDF 内部文字用阅读器自己的搜索框查找。论文右键菜单可批量设状态、星级、标签和论文分组。
6. **对比论文**：按住 Ctrl 多选，点击“对比选中论文”；可勾选字段、只看差异、直接编辑并导出。
7. **备份**：“文件 → 备份与恢复…”备份数据库。完整备份（含 PDF、翻译）应复制整个实际文献库文件夹。

“字段分组”管理卡片表单的章节，“论文分组”整理论文集合，两者独立。

## 论文翻译与卡片技能

技能包位于 [skill/paper-translate-package.zip](skill/paper-translate-package.zip)，可编辑源码位于 `skill/paper-translate-package/`。

在支持技能和文件处理的 ChatGPT 桌面环境导入后，选择“论文翻译与卡片打包”，发送正文 PDF、可选补充材料 PDF 和最新 TXT 卡片模板即可；不用每篇重复粘贴长提示词。若界面需要短文字，写“开始”。

输出为一个论文文件夹及 ZIP：原 PDF 副本、可选补充材料、正文与补充材料合并的一份完整翻译 MD、填好的卡片 TXT。脚本负责页码覆盖、字段完整性及文件校验，翻译与事实核对由模型执行。

以后新增/修改/删除字段，传更新后的 TXT 模板。**系统字段与外部模板不自动同步**；可以在导入向导处理差异。内置模板只是技能创建时的快照。
