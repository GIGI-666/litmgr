（17）论文要解决的问题：从带噪声、多页、密集且题型异质的真实学生手写作业图像中，输出每题完整答案框及有序步骤子框，并满足页面索引、归一化坐标和父子包含关系。难点同时涉及跨页坐标、手写风格/阴影/透视变化、两级结构和跨学科长尾版面。现有自然图像定位、文档内容解析及数学解题评测无法替代这一空间结构评测。

（18）核心思想/关键创新：构建 HG-Bench 两级标注：题目 complete_answer_box 与按书写顺序编号的 step_box，子框须完全包含在父框内，排除印刷题目与教师批改。以页为单位在 IoU≥0.5 下贪心一对一匹配，避免将整份文档框展平。分别用题目区域宏平均 FA 与仅含步骤页面上的微平均 FS^μ 反映粗定位和步骤分解，另报告步骤宏平均、解析成功率、全样本综合分和重复率，以区分空间能力与格式可靠性。用少量领域内 SFT 作为可学习性参考，并做唯一训练样本数量的规模分析与固定训练步数对照。

（19）方法流程图/论文主图流程图：图 1（PDF 第 1 页）概览任务：多页手写输入 → 每题完整答案区域 + 有序步骤区域 → 两级能力对比。图 2（第 4 页）数据引擎：企业答题纸扫描/消费作业照片 → 可用性、批改标记及答案内容过滤 → 10,420 个样本的层级两级标注 → 人工核验并按学科、年级、页数、答案类型分层 → 500 个测试样本与 9,920 个训练样本 → 模式约束的 VLM 输出及页面感知评估。图 5（第 8 页）给出统一提示词、双页输入、预测框与更多学科样本。

（20）训练数据：HG-SFT 最终 9,920 个领域内样本：企业 6,515、消费 3,405，不重新加权。源标注工作形成 10,420 个有效样本，测试各渠道各留 250。附录 B 另报告候选训练池 14,264，经 pHash 过滤移除 4,344 近重复后为 9,920；pHash 汉明距离≤5，并结合用户 ID、采集时间戳精确元数据匹配以检查训练–测试分离。单阶段 SFT 3 epochs/930 steps，全局 batch=32、序列长 32,768、bfloat16、AdamW，峰值/最低 LR=1×10^-6/5×10^-7，30 步 warmup，weight decay=0.1，gradient clipping=1.0；8×H100-80GB，约 3 小时/24 GPU 小时。不使用 RL、合成持续预训练、领域外混合或教师–学生蒸馏。

（21）测试数据：HG-Bench：500 个人工标注 K–12 作业样本，企业/消费各 250，支持单页和多页；5 个学科，平均每样本 1.8 页、每页 5.2 个题目框、有步骤时每题平均 2.9 个步骤框，含步骤页面比例 0.34。标注由 12 位标注者与 5 位高级审核者完成；50 个双人独立标注样本上的平均 IoU=0.86，IoU=0.5 时 85% 框匹配，Cohen κ=0.83、离散字段 Fleiss κ=0.81。测试与训练不重叠。

（22）指标：主要指标：FA 为成功评估样本中的题目级框 F1，先每页算 F1，再在样本内平均，再跨样本宏平均并×100；FS^μ 为仅真值含步骤的页面上全局聚合 TP/FP/FN 的步骤微平均 F1。匹配按页、IoU≥0.5、降序贪心一对一。补充指标：FS^M 为含步骤样本上的不加权宏平均；Succ% 为最多一次格式提醒后返回合规 JSON 的样本比例；S̄ 在全部 500 样本上平均，解析失败计0，PDF 仅描述题目/步骤页面 F1 的加权组合而未写出具体权重；Rep% 为重复输出比例，越低越好，重复样本仍参与评分。注意第 7.1 节 T=0.5/0.7 是样本题目 F1 达标门槛，不是额外实验的 IoU 阈值。

（23）主要结果：表 2（作者报告）：零样本最佳 FA=55.22（Doubao-Seed-2.0-Pro，2026-04-01 评估），最佳 FS^μ=48.22（Gemini-3-Pro-Preview）；参考 GLM-4.6V-9B + HG-SFT 为 FA/FS^μ/FS^M=74.97/72.26/48.25，Succ=100.0%，S̄=71.53，Rep=0.8%，前两项较各自最佳基线提高19.75/24.04点。GLM-4.6V 9B基座=34.15/7.65；397B总参、17B激活的 Qwen3.5=42.71/18.15；GPT-5.4=14.91/1.55；Claude-Sonnet-4.6=16.83/1.63。Doubao 260215 的 FA=52.65，但 Succ=49.4%，S̄仅21.22，说明只看成功样本定位分会忽略格式失败。T=0.5 时115/500样本被全部9个零样本配置遗漏，参考SFT恢复其中68个（59.1%）；T=0.7时全体遗漏223个，恢复45.7%。

（24）实验/消融实验：比较5个闭源 API 评估配置（Doubao含两个时间版本）与4个开放权重基线，另列参考 SFT。图4使用按渠道/学科/页数/答案类型分层的嵌套1k、3k、5k、9.92k训练子集：3 epochs时，1k到9.92k的FA从56.84到74.97、FS^μ从38.72到72.26；5k到9.92k增加8.79个步骤点。固定930步时，FS^μ依次45.18、60.14、67.02、72.26，控制额外优化步数因素。另有学科与1/2/3+页切片、模型间难度一致性、幻觉框/漏步骤/错页/过分割或欠分割/格式失败分析。作者明确未做渠道、监督目标等进一步组件消融。

（25）与我研究方向的关系和启发：基于已核实事实的分析：与文档版面分析直接相邻，将通常的平面区域检测扩展为跨页、父子层级和有序步骤框。可借鉴其按页匹配、父子包含规则、题目宏平均与稀疏步骤微平均的分离，设计结构化版面输出评估；应同时报告格式失败和全样本分数，避免只评成功解析子集。其图4固定优化步数的数据规模对照，对判断领域数据是否带来实际收益有参考价值。以上为基于方法和实验的研究对应分析，本文未验证把该协议或 HG-SFT 直接用于通用印刷文档版面检测的性能收益。
