# litmgr 软件升级版本汇总

从 1.0.0 开始，每完成一项单独登记的改进就加一个末位版本号。末位到十进一位，例如 1.0.9 的下一版是 1.1.0。此前的改动按本对话中实际交付的五轮回溯编号，每轮里相互配合的操作记在同一版本下。历史编号用于追溯，各编号对应的说明不代表都曾单独发布安装包。

| 版本 | 改进 |
| --- | --- |
| 1.0.0 | 起始基线，已有文献管理、卡片导入、检索、PDF 与译文对照阅读。 |
| 1.0.1 | PDF 默认适应栏宽并居中，保留适应宽度入口，支持 Ctrl＋滚轮缩放。[f587cf8 之后的改动 7a53915](https://github.com/GIGI-666/litmgr/commit/7a53915) |
| 1.0.2 | 制作 Windows x64 文件夹版。EXE 随附 Python、Qt、数据库迁移脚本和离线公式资源。[596c8b7](https://github.com/GIGI-666/litmgr/commit/596c8b7) |
| 1.0.3 | PDF 的 Ctrl＋滚轮围绕鼠标位置缩放，保留整体缩放按钮，并提供 Ctrl＋加号/减号与 Ctrl＋0。[23c0408](https://github.com/GIGI-666/litmgr/commit/23c0408) |
| 1.0.4 | 统一浅色界面、11 pt 界面字体和列表间距，调整译文排版及阅读工具栏，显示缩放模式和比例。[46dcae8](https://github.com/GIGI-666/litmgr/commit/46dcae8) |
| 1.0.5 | 加入深夜模式。打开的窗口和译文即时换色，重启记住选择，PDF 原页保留原色。[757e386](https://github.com/GIGI-666/litmgr/commit/757e386) |
| 1.0.6 | 上次使用的文献库被移动、改名或移除时提示重新定位。成功打开文献库后才记住路径。 |
| 1.0.7 | 切换文献库时按源码版或 EXE 使用对应启动参数。无法启动新进程时保留原窗口。 |
| 1.0.8 | 再次打开同一论文的详情或阅读窗口时保留最大化状态。 |
| 1.0.9 | 正文和补充材料各自记住 PDF 页码和缩放。切换文件会取消旧文件尚未执行的跳页。普通打开从首页开始，从最近阅读打开可还原。 |
| 1.1.0 | PDF 搜索显示当前查询进度及结果总数。无匹配时显示“无结果”，清空查询或切换文件时一并清除旧结果。 |
| 1.1.1 | 全文搜索和标签、分组筛选先求候选论文，再读取字段值，减少对无关记录的加载。 |
| 1.1.2 | 导入时只应用参与导入的卡片所带来的字段和别名决定。全部跳过时不会改动字段。 |
| 1.1.3 | 对比表导出为 Markdown 时，标题、字段名和内容中的竖线、反斜杠及换行都能保持在原单元格内。 |
| 1.1.4 | 数据库备份先生成完整副本再正式入列。备份名称精确到微秒，避免连续操作覆盖上一次结果。 |
| 1.1.5 | 恢复前在独立副本上检查数据库并升级旧版本，确认表结构、完整性和外键后才替换当前库。保留恢复前备份及旧版迁移前备份。 |
| 1.1.6 | 在「其他 → 关于」查看当前版本和历次更新。版本汇总随应用保存在资源目录中。 |
| 1.1.7 | 论文翻译技能可在后台导入单篇成品。软件开着时接收论文包并刷新列表，关着时也能直接入库。技能返回论文编号、查重及待归类结果，全程无需操控桌面。 |

从 1.0.6 到 1.1.5 的十项改进一并上传。源码版通过项目中的 `start.bat` 启动。

1.1.5 验收通过 75 项测试及静态检查，覆盖快速切换 PDF、搜索无结果、跳过导入、Markdown 表格导出和备份恢复。源码与 EXE 的切库启动参数均有测试覆盖。

维护记录包括同步 GitHub、打开源码目录、安装并校验 `paper-translate-package`，以及说明如何在 Codex 或 ChatGPT 中使用 Skill。这些操作不计入软件版本号。
