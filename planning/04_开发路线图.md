# 开发路线图

- 第 0 阶段：规划文档、项目骨架、环境验证（PySide6 / QtPdf / QtWebEngine / SQLite trigram）。
- 第 1 阶段：核心与存储（数据库、迁移、字段定义、论文与文件仓库、文献库文件系统）。
- 第 2 阶段：导入（卡片解析器、文件配对、导入服务），用真实卡片做测试。
- 第 3 阶段：基础界面（主窗口、字段管理、详情窗口、字段编辑、检索）。
- 第 4 阶段：阅读（PDF、Markdown + 公式、并排阅读、窗口管理器、多窗口）。
- 第 5 阶段：对比窗口、导出（txt/CSV）、导入向导界面。
- 第 6 阶段：标签、分组、保存的检索、阅读状态与星级。
- 第 7 阶段：笔记、修改历史与撤销、自动备份。

- 摘录/笔记/疑问：笔记已有基础版本；摘录、疑问等专门功能以后再加，现在不做。
- 分组：一篇论文可属于多个分组（已支持）。
- 论文关系：以后可能增加，现在不做。
- 回顾提醒：不需要。
- 阅读历史（2026-11-04 新增）：保留最近阅读的 10 篇；关闭阅读窗口时保存页面状态（所选 PDF/翻译、
  PDF 页码与缩放、翻译滚动位置与字号、显示哪几栏、两栏比例、窗口位置大小）；主窗口“最近阅读”
  下拉菜单（工具栏 + 文件菜单）点击即还原。数据在迁移 0002 的 `reading_history` 表中。
- 其余功能：待试用后根据实际问题确定改进方向。当前状态为“核心版已完成，等待试用反馈”，暂停开发。
