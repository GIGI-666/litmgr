# 编码注释规范

1. 每个 `.py` 文件顶部必须有中文模块文档字符串，包含：
   - 【作用】这个模块是干什么的；
   - 【职责】具体负责的事情；
   - 【依赖】依赖哪些模块；
   - 【被谁调用】谁会用它；
   - 【扩展点】以后想加功能应该改哪里。
2. 每个类、每个公共函数都有中文说明（做什么、参数、返回、注意事项）。
3. 依赖方向：`ui -> services -> storage -> core`，禁止反向 import；界面层不写 SQL。
4. 新增功能优先通过注册表/插件接入，而不是修改已有模块。
5. 注释写“为什么”和“作用”，不复述代码字面意思。
