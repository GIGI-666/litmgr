# 运行与维护说明

## 运行
- 双击 `start.bat`，或在项目目录执行：`.venv\Scripts\python.exe -m litmgr`
- 首次启动会让你选择“文献库文件夹”（PDF、翻译、数据库都存放在里面，复制整个文件夹即可备份/迁移）。
- 命令行指定文献库：`python -m litmgr --library D:\我的文献库`

## 环境
- Python 3.12 + 项目内虚拟环境 `.venv`（依赖见 `requirements.txt`）。
- PySide6 固定为 6.8.3：6.12 在本机上 DLL 加载失败（Qt 与 miniforge 的 VC 运行库不匹配），6.8.3 已验证可用。
- 环境自检：`.venv\Scripts\python.exe scripts\check_env.py`

## 测试
- 单元与界面冒烟：`.venv\Scripts\python.exe -m pytest`
- 截图式界面检查（离屏渲染，输出到 `scripts/_shots/`）：`.venv\Scripts\python.exe scripts\ui_smoke.py`

- 静态检查（未用的导入、未定义的名字）：`.venv\Scripts\python.exe -m pyflakes litmgr tests`

## 日常数据位置
- 配置与日志：`%APPDATA%\litmgr\`（`config.json`、`litmgr.log`）。`config.json` 里的 `ui_state` 保存主窗口位置与分栏；阅读窗口的状态保存在数据库的阅读历史里。
- 数据库：`<文献库>\db\litmgr.db`；自动备份：`<文献库>\backups\`
- **你的文献库**现在位于 `D:\2file\研究生2026.9.7\文献库`，与代码文件夹分开；代码文件夹是 git 仓库（`.gitignore` 已排除 `文献库/`、`*.db`、`.venv/`），文献数据不会被提交。

## 版本管理（git）
- 代码文件夹已初始化为 git 仓库，每个重构批次一次提交，可用 `git log` 查看、`git checkout <提交>` 回退。
- 文献数据的备份靠程序内“备份与恢复”（数据库快照）或直接复制整个文献库文件夹，不走 git。

- 新字段类型：`core/field_types.py` 增加类型并注册（需要特殊的过滤规则就覆盖 `matches`）；`ui/field_widgets.py` 增加控件并 `EDITORS.register`。
